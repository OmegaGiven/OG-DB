How to read the table

  • Surround / spatial is always virtualised — two drivers plus DSP, never discrete channels. What matters is where that DSP runs, which decides what it works with. On the dongle / base station → virtualises any source, including a PS5/Xbox/optical TV feed, no PC needed. In the OS (Dolby Atmos for Headphones — paid ~$15 on Win/Xbox; DTS Sound Unbound; Sony 360 / Tempest 3D on PS5) → source-agnostic but platform-locked. In the vendor app (SteelSeries Sonar, THX Spatial, etc.) → usually Windows-only.
  • Base station + optical input (Arctis Nova Pro, Astro A50 X) is the only setup that can take a Dolby Digital feed from a TV / optical source and virtualise it on the headset's own hardware. A plain USB dongle only ever receives what the host OS sends it.
  • "Simultaneous BT + 2.4 GHz" means game audio on the low-latency link and phone/Discord on Bluetooth at the same time, mixed in your ears. Most headsets only switch between the two.
  • Power. Wired-only entries read "Wired" here; everything else shows rated battery hours. Wireless models still play over USB/3.5mm while charging except dongle-only ones (HyperX Cloud III / Alpha, Logitech G733), which go silent when flat. "2× … swap" = hot-swap batteries, effectively unlimited runtime.
  • Sidetone = hearing your own voice in the cups so you don't shout. The split is whether the level is on a hardware dial (headset or base station) or buried in the app / console menu. Matters more on sealed ANC headsets.
  • Software by OS. The column shows quick per-OS badges; expand a row for what each platform actually loses. Pattern: the full tuning app (EQ, spatial, mic DSP) is Windows-first. Only Logitech / Astro (G HUB) and Audeze (HQ) ship a full macOS app; Corsair's is cut-down; everyone else gives Mac plug-and-play stereo with no EQ or spatial. Linux gets generic USB audio from all of them — no vendor app exists. Console usually means on-headset controls plus the console's own EQ; PS5 adds Tempest / Sony 360 in the system itself.
  • Mic quality is a 4-step read from review consensus — Excellent (broadcast-grade, stream on it) · Very good · Good (clear for chat/calls, a bit compressed) · Average (party chat only). Every model here has a mic; the ones marked Integrated / fixed can't be removed or swapped. Any headset mic still loses to a $60 standalone USB mic.
  • Street prices below are rough Sep-2026 US figures and move constantly — treat MSRP as the anchor.
